Localization & RTL

Pick a language to re-render the flow. For Arabic / Hebrew the layout mirrors so flows read right-to-left (locale.direction: 'rtl'); for every language the screen-reader summaries come from locale.messages. Node titles are translated so the change is visible.

Localized here: the diagram aria-summary, per-flow edge aria-labels, and the nodes-group label (open DevTools to inspect the SVG aria text), plus RTL layout mirroring for Arabic / Hebrew. Defaults (no locale) stay English, left-to-right.
